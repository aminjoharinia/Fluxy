# fluxy_ui

Layout and animation helpers: `FluxyResponsiveView` / `FluxyResponsiveWidget` / `ResponsiveScreen` (phone / tablet / desktop / watch builders), `50.0.hp` / `30.0.wp` screen-percent sizing, and the `.fadeIn()` / `.bounce()` ... animation extensions.

Depends on: fluxy_core, fluxy_state, fluxy_utils.

Part of [Fluxy](../../FLUXY.md), a fork of GetX (MIT, © Jonny Borges).
