# fluxy_state

State management: `.obs` / `Rx*`, `RxList/Map/Set`, `Obx`, `GetX<T>`, `GetBuilder`, `GetxController`, `StateMixin`, workers (`ever`, `debounce` ...) and dependency injection (`Get.put / find / lazyPut`, Bindings). Also `RouterReportManager`, which disposes controllers with their route.

Depends on: fluxy_core.

Part of [Fluxy](../../FLUXY.md), a fork of GetX (MIT, © Jonny Borges).
