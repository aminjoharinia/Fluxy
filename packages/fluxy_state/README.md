# fluxy_state

State management: `.obs` / `Rx*`, `RxList/Map/Set`, `Obx`, `FluxyX<T>`, `FluxyBuilder`, `FluxyController`, `StateMixin`, workers (`ever`, `debounce` ...) and dependency injection (`Fluxy.put / find / lazyPut`, Bindings). Also `RouterReportManager`, which disposes controllers with their route.

Depends on: fluxy_core.

Part of [Fluxy](../../FLUXY.md), a fork of GetX (MIT, © Jonny Borges).
